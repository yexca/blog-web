現在更新於 2026 年 10 月

最近在忙什麼

  1. 01 Agent 與它周邊的 Harness 用 ZeroClaw、Ollama 和 Matrix 組成完全在本機執行的助理，透過 MCP 閘道接上各種工具，也大量使用 Codex 和 Claude Code 來開發。 ZeroClawHarnessVibe coding
  2. 02 本地 AI 流程 ComfyUI 影像工作流程、AI 翻唱的音訊前處理、YOLO 實驗，以及跑在自己機器上的各種模型。 影像模式AI 翻唱音訊YOLO26
  3. 03 自架的家用服務 NAS 上跑著幾個小服務，管理音聲作品、音樂、RSS 和圖片，再用一個起始頁把它們串在一起。 KikotoNAS

原則

我在意的事

本地優先
當資料、模型和控制權放在身邊能讓系統更清楚、更可靠時，就盡量留在身邊。
可檢視
讓輸入、狀態和錯誤都夠透明，才能除錯，也才能持續改進。
可組合
把模型、工具、儲存空間和人的判斷串成同一條工作流程。
值得維護
偏好那些在第一次實驗之後仍然好用的小系統。

專案

反覆出現的問題，變成可重複使用的工具

在家自架

  • kikoto 個人的 DLsite 音聲媒體庫與播放器：用封面瀏覽，依聲優和標籤搜尋，顯示歌詞，也能接續上次的播放進度。 TypeScriptDockerNAS
  • rainy 架在 NAS 上的自架音樂伺服器。 Go音樂
  • pikapu 安靜、自架、只給一個人用的 RSS 閱讀器。 TypeScriptRSS
  • harbor 為 NAS 上執行的各項服務準備的輕量起始頁。 JavaScript起始頁
  • kumo 為個人工作流程設計的輕量圖床服務。 Go圖片

Agent 與 AI 流程

  • home-mcp 給 ZeroClaw 和其他 MCP 用戶端使用的本地 MCP 閘道。 PythonMCP
  • zeroclaw-dockyard 用 Docker 建立並執行多個 ZeroClaw Matrix Agent 的本地 WebUI。 ZeroClawDockerMatrix
  • AI-Cover-Tools 為 AI 翻唱訓練素材提供人聲分離、切片、品質檢查、音高分析和音量標準化。 音訊AIWindows
  • YOLO-Multi 用同一份資料集準備並訓練多組 YOLO 實驗。 YOLOPython
  • lyric-video-template 用 Claude Code 把歌詞影片做成網頁：Canvas 場景與歌詞、節拍同步，並匯出成 MP4。 Claude CodeCanvas

應用程式與歸檔

  • quest-manager 用來管理 Meta Quest 應用程式與檔案的 Windows 桌面程式，支援 APK 預覽與相容性簽署。 Rust桌面程式
  • PixivDownloader-WebUI 用於備份 Pixiv 作品與自動化工作流程的本地 WebUI。 PixivWebUISQLite
  • yasumi 本地優先的規劃工具，幫助專注地管理個人待辦。 GoTypeScript
  • kano-navi 為 kano 製作的粉絲網站。 Go粉絲網站
