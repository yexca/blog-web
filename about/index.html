最近在忙什么

  1. 01 智能体，以及它周围的 Harness 用 ZeroClaw、Ollama 和 Matrix 搭了一个完全本地的助手，通过 MCP 网关接入各种工具，还用 Codex 和 Claude Code 做了不少东西。 ZeroClawHarnessVibe coding
  2. 02 本地 AI 流水线 ComfyUI 图像工作流、AI 翻唱的音频预处理、YOLO 实验，以及在自己机器上跑的各种模型。 图像模式AI 翻唱音频YOLO26
  3. 03 自托管的家用服务 NAS 上跑着一些小服务，管音声作品、音乐、RSS 和图片，再用一个起始页把它们串在一起。 KikotoNAS

原则

我在意的事

本地优先
只要能让系统更清晰、更可靠，就把数据、模型和控制权留在身边。
可检视
让输入、状态和失败足够可见，方便排查和改进。
可组合
把模型、工具、存储和人的判断连成一条完整的工作流。
值得长期维护
宁可做小而精的系统，让它在第一次实验之后依然好用。

项目

反复出现的问题，可以变成反复使用的工具

家里的自托管服务

  • kikoto 个人的 DLsite 音声库与播放器：按封面浏览，按声优和标签搜索，显示歌词，并能接着上次的进度继续听。 TypeScriptDockerNAS
  • rainy 跑在 NAS 上的自托管音乐服务器。 Go音乐
  • pikapu 一个安静的、只给一个人用的自托管 RSS 阅读器。 TypeScriptRSS
  • harbor 给 NAS 上各项服务准备的轻量起始页。 JavaScript起始页
  • kumo 面向个人工作流的轻量图床服务。 Go图片

智能体与 AI 流水线

  • home-mcp 给 ZeroClaw 和其他 MCP 客户端用的本地 MCP 网关。 PythonMCP
  • zeroclaw-dockyard 本地 WebUI，用 Docker 创建并运行多个 ZeroClaw Matrix 智能体。 ZeroClawDockerMatrix
  • AI-Cover-Tools 为 AI 翻唱训练素材提供人声分离、切片、质量检查、音高分析和响度标准化。 音频AIWindows
  • YOLO-Multi 用同一份数据集准备并训练多组 YOLO 实验。 YOLOPython
  • lyric-video-template 用 Claude Code 把歌词视频做成网页：Canvas 场景与歌词、节拍同步，最后导出为 MP4。 Claude CodeCanvas

应用与归档

  • quest-manager 用来管理 Meta Quest 应用和文件的 Windows 桌面应用，支持 APK 预览和兼容性签名。 Rust桌面端
  • PixivDownloader-WebUI 用于 Pixiv 插画备份与工作流自动化的本地 WebUI。 PixivWebUISQLite
  • yasumi 本地优先的计划应用，专注于个人任务管理。 GoTypeScript
  • kano-navi 为 kano 做的粉丝站。 Go粉丝站
